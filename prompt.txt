   * get_servo_postions() -> returns the mappings for which servo means which joint, should be the first tool the llm should use
   * set_servo_angle_by_name(name, angle) -> name should be one of mappings & angles should be between 0 & 180

- additionally, lets also add code transform so the LLM can write code to execute it
